Comandos para iniciar um projeto Git:

1. git init - Inicia um repositorio Git.
2. git status - Mostra o estado dos arquivos.
3. git add - Prepara arquivos para o proximo commit.
4. git commit - Registra uma versao dos arquivos.
5. git push - Envia os commits para um repositorio remoto.
6. git diff - Mostra as alteracoes feitas antes de preparar o commit.
